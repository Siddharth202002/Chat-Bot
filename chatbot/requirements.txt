# Notes
#  1. Required env vars in ../.env :  GROQ_API_KEY, FINNHUB_API_KEY, GROQ_MODEL,
#                                      JINA_API_KEY, JWT_SECRET_KEY
#     Optional: LANGSMITH_TRACING, LANGSMITH_ENDPOINT, LANGSMITH_API_KEY,
#               LANGSMITH_PROJECT, JINA_EMBEDDINGS_MODEL,
#               JINA_EMBEDDINGS_BATCH_SIZE, JINA_EMBEDDINGS_TIMEOUT,
#               JWT_EXP_SECONDS, AUTH_COOKIE_SECURE
#     Long-term memory: MISTRAL_API_KEY (required for extraction),
#               MISTRAL_MEMORY_MODEL, MISTRAL_MEMORY_TIMEOUT,
#               MISTRAL_MEMORY_MAX_ATTEMPTS, MISTRAL_MEMORY_RETRY_BASE_DELAY,
#               MEMORY_EXTRACTION_ENABLED, MEMORY_EXTRACTION_INTERVAL,
#               MEMORY_EXTRACTION_WINDOW, MEMORY_RETRIEVAL_TOP_K,
#               MEMORY_RETRIEVAL_MIN_SCORE, MEMORY_DEDUP_THRESHOLD,
#               MEMORY_UPDATE_THRESHOLD, MEMORY_MAX_PER_EXTRACTION,
#               MEMORY_MAX_CONTENT_CHARS, MEMORY_MAX_PER_USER.
#     See ../.env.example for the full annotated list.
#  2. LINUX SERVER GOTCHA: .env spells the Finnhub key `finnhub_api_key` but
#     the code reads os.getenv("FINNHUB_API_KEY"). Windows env vars are
#     case-insensitive so it works locally; on Linux it resolves to None and
#     the stock tool silently breaks. Rename it to FINNHUB_API_KEY in .env.
#  3. If your machine/network does TLS interception (corporate proxy, or an
#     antivirus like Avast/Kaspersky), Python will fail every HTTPS call with
#     CERTIFICATE_VERIFY_FAILED. Point it at the interceptor's CA, e.g.:
#       set SSL_CERT_FILE=C:\ProgramData\Avast Software\Avast\wscert.pem
#       set REQUESTS_CA_BUNDLE=%SSL_CERT_FILE%
#     and pass `pip install --cert "<same path>"`.
#  4. Frontend deps are separate:  cd frontend-next && npm install
